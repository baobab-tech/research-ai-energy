# ESC Framework: Holistic Approach to Environmentally Sustainable Computing

**Topic:** Data Centers - Power Sources
**Source:** Pazienza, Baselli, Vinci & Trussoni, 2024
**URL:** https://doi.org/10.1007/s11334-023-00548-9

## Insight

This paper introduces the Environmentally Sustainable Computing (ESC) framework as a solution to revolutionize sustainability practices across computing domains. The framework covers the entire lifecycle of computing systems: design, development, monitoring, refactoring, and regulatory compliance. Crucially, it provides industry stakeholders with tools to evaluate and measure sustainability factors, integrate eco-friendly computing principles, and reduce carbon footprint while complying with environmental regulations. The paper showcases real-world use cases including a leading Italian bank implementing carbon-aware computing and Kubernetes cluster resource efficiency optimization - demonstrating practical applications of sustainable computing principles.

## Key Data

- Framework covers full computing lifecycle: design, development, monitoring, refactoring, compliance
- Real-world case studies from banking sector and cloud infrastructure
- Carbon-aware computing implementation demonstrated
- Kubernetes cluster optimization for resource efficiency explored
- Alignment with cloud infrastructure management sustainability trends
